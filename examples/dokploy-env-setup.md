# Dokploy Environment Configuration Reference

Copy and paste the following block into Dokploy's **Environment** tab for your GS-AI-CLOUD Stack:

```env
DOMAIN=ai.yourdomain.com
ACME_EMAIL=admin@yourdomain.com
POSTGRES_USER=gscloud
POSTGRES_PASSWORD=generate_a_secure_password_here
POSTGRES_DB=gscloud
REDIS_PASSWORD=generate_a_secure_redis_pass
MINIO_ROOT_USER=minio_admin
MINIO_ROOT_PASSWORD=generate_a_secure_minio_pass
QDRANT_API_KEY=generate_a_secure_qdrant_key
LITELLM_MASTER_KEY=sk-generate-a-secure-master-key
GRAFANA_ADMIN_USER=admin
GRAFANA_ADMIN_PASSWORD=generate_a_secure_grafana_pass
```
